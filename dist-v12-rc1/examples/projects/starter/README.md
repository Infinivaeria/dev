# Selenite Project

Open this folder with `selenite --ide .`. Run it with `selenite --project .`.

The project manifest selects the Ruby entry point, game/app mode and JSON grid save.
Use the IDE's Help tab for Ruby, raylib, storage, networking and game tutorials.

Game projects use WASD or arrow keys to move the blue player; Escape exits.
Application projects run without a graphics window and persist their run count.

Keep project entry/grid paths relative. Generated saves are local application data.
